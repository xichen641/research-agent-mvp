信息流图另经页面渲染核对。这里只记录题库审校，不是被测智能体的回答评分或

## 需要保留的不确定性

- CLIP-ReID p6 的 Table 3 对 VehicleID 列出 R1/R5，ViT CLIP-ReID 行为 85.3/97.6；
  邻近正文把同一数值写作 mAP/R1。题库要求显式指出差异，不能填造 VehicleID mAP。
  此处也不能忽略该表 small subset 的条件，或把正文标签当成已经校正的结论。
- IDEA p7 Figure 4 的 prompt length 与 p4 的可学习前缀相关；曲线在选定配置
  后存在下降，而邻近段落有“增长”概括。不能将其用于证明 caption 字数越多越好。
- NEXT p7 Table 4 的 Quality 是作者加噪消融设定。100% 不自动表示每个属性都
  经人工确认，35%/70% 也不自动表示错误属性的确切比例；给定段落没有说明清楚
  的噪声构造，应另查实现，不能由评审者或回答补造。
- IDEA p16 Table 13 的 M(X) 定义为对应文本空字符串；保留图像输入。Table 12
  的模态组合和 p7 Table 6 的无文本模型属于不同干预，不能混用差值作因果结论。
- MP-ReID 使用人工标注属性数据，原文的隐式提示定义也应原样保留。未经代码
  核对，不把测试时实时大模型调用、re-ranking 或隐式张量索引写成已验证事实。
- PDF 内有代码/数据或硬件描述，不证明本地已经具备它们。题目中的 12GB、一天、
  20 图检查和 E1 实验报告均属合成条件，不能当作用户实际资源或本地运行结果。

## 评审使用与复验

[任务集](../datasets/reid_research_tasks.jsonl)记录实际来源、可接受语义、必要分析、
错误边界与下一步。[人工评审标准](reid_research_review.md)已同步更新，并明确：
只将题目与实际材料给被测智能体，gold 与评分要求由评审者使用；背景事实按本题
问题选择，不要求无关数字全量复述；识别原文冲突属于正确分析。

```powershell
.\scripts\check-reid-research-tasks.ps1 -Docker
```

预期：`status=passed`、`task_count=20`、五类各 4、`checked_pages=21`、
`checked_excerpt_references=125`、`answer_quality_evaluated=false`。
原文匹配只能证明片段位于指定材料页，解释与评价仍须结合完整原页及本题问题。
本轮没有执行真实模型任务，也没有写入实测回答、分数、延迟、Token 或费用。
